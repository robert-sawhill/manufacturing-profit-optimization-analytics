# 📊 Manufacturing Operations & Profit Optimization Analysis
An end-to-end data analytics project translating complex operational data into actionable financial insights. This project utilizes Python for statistical modeling and regression diagnostics, structured datasets for robust data hygiene, and Tableau for executive-level visualization—ultimately modeling a **$1.4M profit optimization** while respecting critical manufacturing resource constraints.

---

## 🚀 Executive Summary
Manufacturing operations often struggle with balancing batch production costs, labor hours, and raw material expenses across diverse product lines. This project analyzes operational data to identify primary cost drivers, evaluate statistical significance, and simulate an optimal production scheme that models significant profit optimization.

---

## 🛠️ Tech Stack & Skills Highlighted
* **Languages & Tools:** Python (Pandas, NumPy, Statsmodels), Excel Solver, Tableau / Power BI.
* **Statistical Methods:** Multiple Linear Regression, Collinearity Diagnostics (VIF), Residual Analysis, ANOVA, t-tests.
* **Business Domains:** Supply Chain Analytics, Cost-Benefit Analysis, Prescriptive Modeling.

---

## 📈 Key Methodology & Analysis

### 1. Data Cleaning & Exploratory Data Analysis (EDA)
* Handled missing values, standardized product line metrics, and structured raw material batch inputs.
* Evaluated resource constraints across blending rooms, machine hours, and direct labor man-hours.

### 2. Statistical Modeling (Regression & Diagnostics)
* Built a **multiple linear regression model** to predict product profit based on production costs, labor, and overhead.
* Validated model assumptions by checking for multicollinearity (Variance Inflation Factor / VIF) and analyzing the normality of residuals.

### 3. Prescriptive Simulation & Optimization
* Utilized constraint-based modeling to determine the optimal product mix.
* **Result:** Demonstrated a pathway to maximize profitability up to **$1.4M** while staying within strict capacity boundaries.
